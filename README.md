## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

## Deploy

Use a free Render Web Service connected to this GitHub repository.

Build command:
pip install -r requirements.txt

Start command:
gunicorn app:app

The public URL can then be shared on WhatsApp.
